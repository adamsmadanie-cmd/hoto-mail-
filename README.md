# Hoto 🚀

**Hoto** est une application web minimaliste et moderne qui permet de recevoir de l'argent partout dans le monde et d'être notifié directement dans sa boîte Gmail.

## Fonctionnalités

- **Lien de paiement personnel** : Partagez un lien unique pour recevoir des paiements.
- **Multi-devises & Multi-supports** : Compatible avec Mobile Money (Afrique) et cartes bancaires, Apple Pay, Google Pay (International via Stripe / Flutterwave).
- **Notifications Gmail** : Chaque paiement confirmé déclenche une notification instantanée sous forme d'e-mail.
- **Sécurité PIN** : Retraits protégés par un code PIN à 4 chiffres avec verrouillage temporaire en cas d'erreurs multiples.

## Installation & Utilisation

1. Clonez ou téléchargez ce dépôt sur votre machine ou directement depuis GitHub.
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne.
3. Testez l'interface interactive complète (connexion, simulation de paiements, génération de liens et retraits).

## Technologies utilisées
- HTML5, CSS3 (Variables, Design Grid/Flexbox)
- JavaScript Vanilla (Interactivité, Gestion d'état locale)
